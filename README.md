## 📱 CodeNest Nedir?

CodeNest, mobil cihazlarda kod yazmayı ve **anında çalıştırmayı** mümkün kılan, kullanımı kolay bir Android kod editörüdür. Diğer mobil editörlerin aksine, HTML/CSS/JavaScript ve Python gibi dilleri cihaz üzerinde çalıştırıp sonucu anında görmenizi sağlar.

## ✨ Özellikler

- 🎨 **Sözdizimi Renklendirme (Syntax Highlighting)** — Kodunuzu okunaklı hale getirir
- ⚡ **Anında Çalıştırma** — HTML, CSS, JS ve Python kodlarını cihazda test edin
- 🌗 **Karanlık/Aydınlık Tema** — Göz yormayan kullanım
- 📁 **Dosya Yönetimi** — Proje ve dosyalarınızı düzenleyin
- 🔍 **Arama & Değiştirme** — Kod içinde hızlı gezinme
- 📴 **Çevrimdışı Çalışma** — İnternet bağlantısı gerektirmez (çalıştırma motoru cihaz üzerinde)

## 🚧 Proje Durumu

> Bu proje şu anda **aktif geliştirme aşamasındadır**. GitHub Actions üzerinden otomatik build alınmaktadır.

## 🛠️ Kullanılan Teknolojiler

- **Kotlin** — Ana geliştirme dili
- **WebView** — HTML/CSS/JS önizleme motoru
- **Pyodide / Chaquopy** — Python çalıştırma desteği (değerlendirme aşamasında)
- **GitHub Actions** — CI/CD ve otomatik APK build

## 📦 Kurulum (Geliştiriciler için)

En son build'i almak için:
1. [Actions](https://github.com/TheE1even11/codenest/actions) sekmesine gidin
2. En son başarılı workflow çalışmasına tıklayın
3. **Artifacts** bölümünden APK dosyasını indirin
